How to Play

What is a slope field?

A slope field for y' = f(x, y) draws a short arrow at every grid point (x, y) showing the direction any solution curve must travel.

The red curve

The red curve is a particular solution of y' = f(x, y) starting at the red dot, traced in both directions.

Your goal

Find f(x, y) so the curve exits through both yellow boundary segments. When solved, press ↺ Reset for a new puzzle.

Supported syntax

Variables x and y · operators +, -, *, /, ^ · functions sin, cos, tan, exp, ln, sqrt, etc.

Try: x  ·  -y  ·  x+y  ·  x^2-y  ·  sin(x)*cos(y)

Solve button

Stuck? Press Solve and the game will find a simple f(x, y) that works.
